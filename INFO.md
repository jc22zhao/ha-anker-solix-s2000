# Anker Solix — SOLIX S2000 (AS220) fork

Fork of [thomluther/ha-anker-solix](https://github.com/thomluther/ha-anker-solix) adding support
for the **SOLIX S2000 (AS220)**. Nearly all the work is Thomas Luther's — see the README for full
credit, and [sponsor him](https://github.com/sponsors/thomluther) if this is useful to you.

Tested on exactly one S2000 (firmware 1.0.2.2, CA). **No guarantee it works on any other unit or
device.** If you do not have an S2000, use upstream instead.

Full documentation lives in the
[upstream README](https://github.com/thomluther/ha-anker-solix/blob/main/README.md).
